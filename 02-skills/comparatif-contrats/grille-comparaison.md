# Grille de comparaison de contrats

La méthode du cabinet. Tout est comparé **à documentation égale** : si une information manque pour un contrat, la case indique « non documenté » et la ligne est signalée dans les données manquantes.

## 1. Carte d'identité

Par contrat : assureur (et sa juridiction, France ou Luxembourg), nom commercial exact, type (assurance-vie, capitalisation), date et version des documents fournis, minimum de versement initial et complémentaire.

## 2. Les frais, cinq étages

| Étage | Ce qu'on relève |
|---|---|
| Frais sur versement | Taux affiché, caractère négociable si documenté |
| Gestion du contrat, fonds euros | Taux annuel |
| Gestion du contrat, UC | Taux annuel |
| Arbitrage | Par opération, forfait, gratuité éventuelle (en ligne) |
| Options | Gestion pilotée, garantie plancher, autres, avec leur coût |

Puis la **simulation sur le cas du client** : coût annuel estimé en euros pour le montant et la répartition envisagés, calcul ligne à ligne affiché. Toujours préciser : hors frais courants des supports, qui dépendent de l'allocation choisie (à comparer séparément si les listes de supports sont fournies).

## 3. Univers et services

- Taille de l'univers de supports et catégories couvertes (ETF, immobilier, structurés, titres vifs, non coté)
- Fonds euros : conditions d'accès (part d'UC minimum exigée), rendement historique si documenté (avec les années)
- Options de fonctionnement : versements et rachats programmés, sécurisation des plus-values, avance, nantissement
- Modes de gestion : libre, pilotée, sous mandat
- Qualité de service si documentée : extranet, délais d'arbitrage

## 4. Adéquation au besoin exprimé

Un tableau critère par critère : le besoin du client en ligne, les contrats en colonne, la réponse factuelle dans la case (« oui, documenté p. X », « non », « non documenté »). Aucune pondération, aucun score.

## 5. Observations

Uniquement les différences **réellement significatives** (un écart de 0,05 % de frais de gestion n'en est pas une ; l'absence d'une option demandée par le client en est une). Format : « Observation : ... Point à explorer avec le conseiller : ... »
