# Niveau 1 : les prompts

Des textes prêts à copier-coller dans [claude.ai](https://claude.ai). Zéro installation.

## Comment utiliser (3 minutes)

1. Ouvrez le fichier du prompt qui vous intéresse.
2. Remplacez l'en-tête « Votre cabinet » (nom, statuts ORIAS, ton).
3. Collez le tout dans une nouvelle conversation Claude.
4. Joignez les pièces demandées (⚠️ anonymisées).
5. Si l'assistant vous dit qu'il lui manque des éléments : c'est normal et voulu. Il ne produit rien sans ses entrées.
